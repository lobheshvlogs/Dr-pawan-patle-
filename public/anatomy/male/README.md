# Male Anatomy 3D Model Asset Directory

Place your properly licensed male anatomical 3D model here:
`body.glb`

Path:
`/public/anatomy/male/body.glb`

The portfolio's Three.js WebGL viewer automatically loads this file via GLTFLoader (with DRACOLoader compression support) when the user selects the [ MALE ] toggle.

Supported mesh structures:
- Skeleton (skull, spine, rib_cage, pelvis, femur, etc.)
- Organs (brain, heart, lungs, liver, stomach, kidneys, intestines)
- Muscles (pectoralis, deltoid, biceps, abdominals, quadriceps, etc.)
- Vascular (arteries, veins)
- Nerves (spinal cord, peripheral nerves)
