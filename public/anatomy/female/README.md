# Female Anatomy 3D Model Asset Directory

Place your properly licensed female anatomical 3D model here:
`body.glb`

Path:
`/public/anatomy/female/body.glb`

The portfolio's Three.js WebGL viewer automatically loads this file via GLTFLoader (with DRACOLoader compression support) when the user selects the [ FEMALE ] toggle.

Supported mesh structures:
- Skeleton (skull, spine, rib_cage, female gynecoid pelvis, femur, etc.)
- Organs (brain, heart, lungs, liver, stomach, kidneys, intestines, uterus, ovaries)
- Muscles (pectoralis, deltoid, biceps, abdominals, quadriceps, etc.)
- Vascular (arteries, veins)
- Nerves (spinal cord, peripheral nerves)
